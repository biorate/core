Interface ProjectConfig

Description

The shape a project configuration file (.hygen.*) may declare. Compile-time contract only: used to type object or class configs (export default class Config implements ProjectConfig); the runtime merge does not depend on it. Intentionally narrower than RunnerConfig — transport concerns (logger, exec, createPrompter) stay programmatic.

Optional argCase

argCase?: "keep" | "upper-underscore"

Description

Controls how CLI flag keys are normalized before they become template locals and hook args keys. 'keep' (the default) preserves flag keys exactly as parsed; 'upper-underscore' normalizes hyphenated and camel-cased keys to UPPER_UNDERSCORE form. Reserved keys (_, ts, name, generator, action) are never normalized.

Description

Extra helpers merged with the built-in ones. Either a plain map, or a factory receiving the (pre-merge) locals and a subset of the runner configuration so helpers can be computed from context.

A factory is invoked for every template render (frontmatter attributes and body) with that action's locals, and lazily once per run (from the CLI arguments, positionals under _) when lifecycle hooks or a class prompt section read h. It must be re-entrant and must not depend on per-template or prompt-provided values.

Description

Project-level lifecycle hooks merged from the nearest .hygen.* configuration file. They wrap every run of every generator; action-level hooks.* methods compose inside them (before*: project → action, after*: action → project).

Optional params

params?: ParamsSchema

Description

Global declarative parameter schema, merged from the project configuration (.hygen.*). The same descriptor shape as an action's static params; prompted once per run, before the pair loop, and merged into the base arguments so every pair sees the values. An action-level descriptor with the same name overrides the global one with a warning.
