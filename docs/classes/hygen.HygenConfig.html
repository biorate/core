Class HygenConfigAbstract

Description

Abstract base class for project configuration files (.hygen.*, default export). Extending it turns the config into a full-featured class: state lives in constructor-initialized fields, and lifecycle hooks are prototype methods with a live this — no nested hooks: { ... } object required.

Example

import { HygenConfig } from '@biorate/hygen';

export default class Config extends HygenConfig {
  private count = 0;
  constructor() {
    super();
    this.templates = '_templates';
  }
  // helpers as a factory method (a property or getter works too)
  helpers() {
    return { fromConfig: (s: string) => `cfg:${s}` };
  }
  // hooks as prototype methods, `this` is the config instance
  beforeEach(ctx) {
    this.count += 1;
    ctx.logger.log(`pair #${this.count}`);
  }
}

Description

Extra helpers merged with the built-in ones. A subclass may provide this member in any of three forms: an own property map, a getter returning a map, or a factory method (locals, config) => Helpers (invoked per render, like the factory form of RunnerConfig.helpers). Note: an own property shadows a prototype method — use one form per class.
